# 项目概览

租房搜索聚合平台。面向国内租房人群，搜索中文互联网上的租房信息，支持筛选排序。

## 目标

做杭州最好的租房聚合搜索工具。先验证 MVP，再扩展。

## MVP 范围

- **城市**: 仅杭州
- **来源**: 豆瓣租房小组 + 闲鱼
- **筛选**: 价格、户型、租赁方式（整租/合租/单间/转租）、房东类型（个人/中介）、来源、发布时间
- **排序**: 综合、最新、价格、距离（高德地图）
- **订阅**: 邮件通知
- **地图**: 高德地图标注

## 非目标

- 不做交易、不做 IM、不做房源发布
- 阶段 B 之前不做贝壳/58/小红书
- 阶段 B 之前不做微信通知

**Why:** 产品经理的 side project，预算有限，技术小白。需要先验证核心流程。
**How to apply:** 所有设计决策以此为边界，超出 MVP 范围的放到阶段 B。
