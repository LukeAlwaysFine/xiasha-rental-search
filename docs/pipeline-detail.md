# 抓取与过滤机制

## 1. 关键词生成

三样东西混合拼出 ~165 个搜索词：

- **15 个下沙子区域**：金沙湖、高沙、文泽路、下沙江滨、云水、工商大学、杭师大、财经大学、传媒学院、福雷德、和达城、宝龙、龙湖天街、银泰、奥特莱斯
- **8 种租房类型**：租房、转租、整租、合租、单间、一室、两室、公寓
- **40 个小区/公寓名**：伊萨卡国际城、世茂江滨花园、保利东湾、宋都晨光国际…

组合：`"{区域} {类型}"` + `"杭州下沙 {小区名}"`，去重后约 165 个。

## 2. 闲鱼抓取（MTOP API 拦截）

Playwright 打开 Chrome，用闲鱼 cookie 登录态，逐个关键词搜索。

`page.on("response")` 钩子截获 MTOP API 返回的 JSON，不等页面渲染完成，直接从 JSON 提取结构化字段：

| 字段 | 来源 |
|------|------|
| title | JSON 直接提取 |
| price | JSON 直接提取 |
| images | JSON 直接提取（多字段名合并去重） |
| lng / lat | JSON 6 路径探测，覆盖率 99.8% |
| poster_id | userNickName 提取 |
| address | location + area 拼接 |
| seller_item_count | 偶尔有，卖家总房源数 |

每个关键词只能拿到第一页（30 条），翻页需要动态签名，无法通过。

同时把标题和描述拼成文本（content），留给下一步 AI。

## 3. AI 提取

DeepSeek V4 Flash（AsyncOpenAI，thinking=disabled，40 并发）。

只提取房源信息，不管中介判断：

```
价格（纯数字）、户型、地址（必须含"杭州"）、面积、
整租/合租/转租、联系方式、发帖人 ID、是否转租、
发布时间、图片 URL 列表
```

AI 返回 `is_rental: false` → 直接丢弃（非租房内容：卖显卡、求合租、搞活动等）。

## 4. 三道过滤

### 价格过滤

- 月租 < 300 → 丢弃（车位、杂物间）
- 月租 > 50000 → 丢弃（商铺、写字楼）

### 地址过滤

- 不含"杭州" → 丢弃

### 标题黑名单

30+ 非租房关键词命中即丢弃：

```
会员、年卡、硬盘、显卡、手机、笔记本、摩托车、二手车、
代购、拼单、聚餐、打球、征友、交友、商铺、店面、写字楼、
车位、仓库、厂房、棋牌室、服装店、直播间、带货…
```

## 5. 坐标补齐

API 未提供坐标时，用地址调高德地图查经纬度。

## 6. 初判中介（入库瞬间）

不调 AI，纯本地规则。**四条铁证命中即"中介"**：

| 铁证 | 来源 |
|------|------|
| 内容含品牌名（自如、贝壳、链家、我爱我家…） | regex 匹配 |
| 发帖人昵称含商业词（租房、公寓、管家、房产…） | regex 匹配 |
| 库里同 poster ≥3 条 | 数据库统计 |
| 闲鱼 API 返回卖家房源 ≥3 | MTOP 直接提供 |

四条都不命中 → **"疑似中介"**。

程序在入库这一步**永不标"个人"**。

弱信号（中介话术如"多套在租""随时看房"、模板化标题无个人语言）→ 也标"疑似中介"。

## 7. 入库去重

`source_url`（帖子链接）为唯一键，同一条帖子不会存两份。

URL 重复时 UPSERT 合并：新数据补旧数据的缺失字段，中介标记只升不降（中介永不降级，个人→中介可升级，个人不降级为疑似中介）。

## 8. Poster 主页检查

### 触发方式

- 手动抓取完成后自动触发（2 秒延迟，fire-and-forget）
- 每 6 小时定时任务

### 流程

Playwright 打开闲鱼，找到未核实过的发帖人，逐一进主页数：

1. 出租房数量（标题含 整租/合租/转租/一室/㎡/月/出租… 等关键词）
2. 总物品数量（所有在售商品）

### 判定规则

| 出租数 | 总物品 | 结论 |
|:---:|:---:|------|
| ≥3 | 不限 | **中介** |
| 2 | 不限 | 疑似中介 |
| 1 | =1（无其他闲置） | 疑似中介 |
| 1 | >1（有其他闲置） | **个人** |

### 与初判融合

| Poster 结论 | 初判 | 最终 |
|:---:|:---:|:---:|
| 中介 | 任意 | **中介** |
| 疑似中介 | 中介 | **中介** |
| 个人 | 中介 | **疑似中介** |
| 其他 | — | 按 Poster 结论 |

### 缓存

- "个人"：24h 内不重查
- "疑似中介"：6h 内不重查
- "中介"：已排除（≥3 条不会再进待查列表）

## 一图流

```
点按钮
  → 拼 165 个关键词
  → Playwright 截获 MTOP API JSON
  → AI 提取（户型/地址/面积/转租/联系方式）
  → 价格 <300 或 >50000 → 扔
  → 地址不含"杭州"     → 扔
  → 标题含黑名单词      → 扔
  → 四条铁证查中介      → 命中→中介，否则→疑似中介
  → 入库（URL 去重）
  → 自动触发 Poster 主页检查
  → 每 6h 定时重查未核实的 poster
```
